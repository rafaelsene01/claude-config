## Arquivos proibidos de leitura

Nunca leia, mostre ou referencie os seguintes arquivos:
- .env* (variáveis de ambiente)
- *credentials*, *.pem, *.key
- ~/.npmrc (tokens npm)
- ~/.ssh/* (chaves SSH)
- ~/.aws/*, ~/.gcp/*, ~/.azure/*

Se o usuário pedir explicitamente para ler, avise antes.
